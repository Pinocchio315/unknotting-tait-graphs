# Deposited records for manuscript version 1.3 and earlier versions

These files accompany **Computation of Unknotting Numbers: Which Knot Breaks the
Bernhard–Jablan Conjecture?**. They distinguish input ranges, completed lower-bound verdicts,
explicit upper-bound certificates, and exploratory data.

The current aggregation entry point is `../consolidate_results.py`. It reads
deposited inputs and writes only to `../generated/`; it does not replace the
historical aggregates in this directory.
The current rebuilt counts are **2,719 exact values and 390 further improved
ranges**. The exact values consist of 2,149 knots with `u=2`, 373 with `u=3`,
172 with `u=4`, and 25 with `u=5`. Lower bounds determine 2,711 exact values;
eight explicit unknotting diagrams determine the remaining eight.
For v1.3, `generated/paper_v1_3/counts.tex` and six appendix-row files are
regenerated by the same script and included directly in the manuscript.
The read-only `../verify_manuscript.py` checks these inputs against exact
regeneration before comparing the completed manuscript with the data.

`python consolidate_results.py --manuscript v1.3` is the default current
profile. `--manuscript v1.2` preserves the earlier totals of 1,227 exact values
and 176 improved ranges. Use a separate `--outdir` when comparing profiles.

- `comparison/baseline_overrides.csv`, `september_comparison.csv`, and

Run `python audit_knotinfo_releases.py --verify` from the repository root
for a read-only reproduction. The 2,719 exact determinations split into
194 agreeing September exact values, nine conflicting September exact
values, and 2,516 September unresolved entries. A tenth disagreement is
the non-exact interval for `13a_650`. The three newly conflicting exact
values are `u(13n_111)=u(13n_142)=u(13n_196)=3`, against two in the package.
These conflicts are reported rather than silently combined with the computed
lower bounds. Excluding the ten conflicts, 94 retained upper bounds exceed
the September values: 85 entire intervals are weaker and nine are incomparable.

This provenance distinguishes historical-baseline improvements, agreement
with independently tabulated values, and unresolved release discrepancies.
Checksums detect input changes; they are not proofs of the mathematics or
an assertion that a live KnotInfo page has the same contents.

The snapshot retains `[1,3]` for `13n_3370`. The published bound `u <= 2` from
Brittenham–Hermiller, Theorem 1.3(a) and Lemma 2.5, is therefore supplied as a
separate input in `bernhard_jablan/brittenham_hermiller_upper_bounds.json`.
This file also records their upper-bound construction for `12n_491`.
The two new Greene lower bounds, combined with these existing upper bounds,
increase the exact-value count by two. In particular, the former construction
is not treated as a new upper-bound result of this paper.

For `13n_1587`, the historical braid certificate supplies the published
upper bound two and the new Greene calculation supplies the matching lower
bound. **Erratum to the unchanged descriptive fields of
`13n_1587_u_le_2_braid_certificate.json`:** the construction is from
Brittenham–Hermiller §3; the Applebaum attribution is not its original
source. The file's `[1,2]` and unresolved wording describe the historical
upper-bound stage. The value is now two. Keeping this archival file unchanged
preserves its earlier checksums and does not change the verified braid words.

The earlier Greene records give `u(12n_491) = u(13n_3370) = 2`. Together with
the enlarged sweep, method tag `G` now accounts for 1,494 exact values and
215 improved ranges. With `u(12n_288) = u(12n_501) = 2`
from `montesinos/`, they identify `13n_3370` as a counterexample to the
Bernhard–Jablan conjecture by
[Brittenham–Hermiller, Theorem 1.3](https://arxiv.org/abs/1705.05985v2).
Appendix H prints the exact correction terms for `12n_491` and the remaining
candidate sets for `13n_3370`, using one representative of each conjugate pair.
`verify_manuscript.py` compares all 52 printed representatives with these records.

The Appendix F conclusion is conditional on the Bernhard–Jablan property; its
959 knots are not part of the unconditional exact-value count. The 1,027
parent knots divide into those 959, 22 parents with 11 named possible child
knots, and 46 parents whose proposed exclusions rely on Jones-only
identifications. The latter comprise 39 heuristic zero-candidate records
and seven additional proposed composites. Neither subgroup is a proved
dichotomy.

The `u1_*_diagram_scan` records examine one diagram of each knot. For the
nonalternating knots, a negative result does not imply the absence of an
unknotting crossing in another minimal diagram. It also does not establish
a lower bound two. In contrast, the positive records are explicit
unknotting-crossing certificates for the displayed diagrams.

The new `u(13n_1587)=2` result narrows, but does not uniquely identify, the
strong counterexample in that example. The complete six-member BJ set of
`14a2539` is recorded and independently replayed in
`review_v1_3/bjset14a2539_replay.json`. Exact pass moves and one flype identify
its `12a684` children in `12a684_exact_identification.json`; the other
identifications also match independent canonical diagram signatures.

Historical
comparison and exploratory files, including those in `dkt/`, are preserved as
archival records rather than additional contributions. Per-shard working files
are not deposited.

The verification commands in the directory READMEs exercise the mathematical
kernels, known examples, and deposited unknotting certificates. Rebuilding these
aggregate files does not rerun every obstruction or reidentify every crossing
neighbor used in the conditional Appendix F analysis.
The review notes and replay scripts in `review_v1_3/` record the exact scope
of the mathematical, arithmetic, diagram and reporting checks.
